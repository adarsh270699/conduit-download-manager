# Go module licenses

This directory contains the license texts for the Go modules linked into the
Conduit desktop and daemon binaries. The versions are listed in
[MODULES.txt](MODULES.txt). The full dependency graph is pinned by
`desktop/go.sum` and `daemon/go.sum`.

`Go-LICENSE` is the license for the Go standard library and runtime.

The browser extension has no third-party runtime dependencies.

To refresh this directory, follow the instructions in
[../README.md](../README.md#refreshing-the-go-licenses).
